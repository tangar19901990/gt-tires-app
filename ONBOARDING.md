# Як підключити нового клієнта (окрема копія)

Рецепт для варіанту "окрема копія на кожного клієнта".
Проходити по пунктах зверху вниз, нічого не пропускати.

---

## 1. Новий репозиторій
- Створити новий репозиторій на GitHub, назва: `gt-tires-app-<назва_клієнта>`
- Скопіювати туди файли з `gt-tires-app` (мінімум: `gt-tires-v4-supabase-ready.html`,
  `app.js`, `styles.css`, `print.js`, `manifest.json`, `service-worker.js`, `icons/`)

## 2. Новий Supabase-проєкт
- Створити окремий Supabase-проєкт для цього клієнта (свої дані, ізольовано від GT Tires)
- Застосувати ту саму структуру таблиць, що в `gt-tires` (`v4_clients`, `v4_orders`,
  `v4_order_items`, `v4_products`, `v4_payments`, `v4_cash_operations`, `v4_settings`)
- В адмінці клієнта (поле `supaUrl` / `supaKey`) вписати дані нового проєкту

## 3. Заміна брендингу в коді
Знайти і замінити в `gt-tires-v4-supabase-ready.html` та `app.js`:
- Назва бізнесу (GT Tires → назва клієнта)
- Адреса (Велика Димерка, вул. Соборна 106 → адреса клієнта)
- Телефон / Telegram-контакт
- Прайс-лист (199 позицій GT Tires → прайс клієнта, або лишити як шаблон і клієнт сам редагує)

## 4. Запис у таблицю licenses
У проєкті `gt-tires` (Supabase) в таблиці `public.licenses` додати рядок:
```sql
insert into public.licenses (client_slug, business_name, paid_until, is_active)
values ('<slug_клієнта>', '<Назва бізнесу>', '<дата оплати>', true);
```
⚠️ У самому коді копії клієнта в блоці перевірки ліцензії (`LICENSE_URL`, `LICENSE_KEY`,
`CLIENT_SLUG`) — `CLIENT_SLUG` має співпадати з тим, що вписано тут.

## 5. Деплой
- Settings → Pages → гілка `main`, корінь `/` (як в основному репо)
- Перевірити продакшн-адресу: `<github_username>.github.io/gt-tires-app-<клієнт>`

## 6. Перевірка перед передачею клієнту
- [ ] Відкривається без помилок
- [ ] Правильна назва/адреса/телефон скрізь у інтерфейсі й на друку
- [ ] Прайс актуальний
- [ ] Supabase-синхронізація працює (створити тестове замовлення, перевірити в базі)
- [ ] Перевірка ліцензії працює (тимчасово вимкнути `is_active`, перевірити блокування, увімкнути назад)
- [ ] PWA встановлюється на телефон клієнта

## 7. Оплата (поки вручну)
- Клієнт переказує оплату на Mono
- Після підтвердження — оновити `paid_until` в таблиці `licenses`:
```sql
update public.licenses set paid_until = '<нова_дата>' where client_slug = '<slug_клієнта>';
```
