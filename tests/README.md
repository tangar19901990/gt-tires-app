# Тести GT Tires CRM

## Що це
`smoke-test.js` — автоматична перевірка критичної бізнес-логіки перед заливкою змін.
Ловить типові регресії за секунди замість того, щоб шукати їх вручну на телефоні.

## Що перевіряється
1. Категорії — CAT_META, PRICE_LIST і CAT_ICONS не розсинхронізовані (саме через це були проблеми з "Латки легк." і зсувом картинок)
2. Немає дублікатів id серед послуг, у всіх коректна ціна й назва
3. Усі критичні функції (addOrderSvc, saveNewOrder, printOrderNariad тощо) існують і не видалені випадково
4. Симуляція реального додавання послуги в замовлення — перевіряє, що ціна рахується правильно

## Як запустити
```bash
npm install
node app.js       # (файл має лежати поруч — скопіюй свіжий з репо)
node smoke-test.js
```

Вихід "✅ УСІ ПЕРЕВІРКИ ПРОЙДЕНО" — можна заливати.
Вихід "❌ ЗНАЙДЕНО ПРОБЛЕМ" — текст помилки покаже точно що і де зламано.

## Коли запускати
Після кожної суттєвої правки в app.js — особливо після зміни категорій,
масиву PRICE_LIST або видалення/перейменування функцій.
