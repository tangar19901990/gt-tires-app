# Тести GT Tires CRM

## Що це

Автоматична перевірка перед заливкою змін. Комп'ютер сам запускає CRM у пам'яті,
тикає по ній і каже, чи щось зламалось. Ловить те, чого не видно очима:
сторінка виглядає нормально, а всередині поламано.

## Як запустити

```bash
cd tests
npm install      # один раз
npm test
```

`✅ Все чисто — можна заливати` → пушиш.
`❌ Провалено` → текст покаже точно що і де.

Окремо:
```bash
npm run test:logic    # тільки бізнес-логіка
npm run test:panel    # тільки панель top_secret
```

## Набори

### smoke-test.js — бізнес-логіка

1. **Категорії** — CAT_META, PRICE_LIST і CAT_ICONS не розсинхронізовані
   (саме через це були проблеми з «Латки легк.» і зсувом картинок)
2. **Послуги** — немає дублікатів id, у всіх коректна ціна й назва
3. **Критичні функції** — `addOrderSvc`, `saveNewOrder`, `printOrderNariad` тощо
   існують і не видалені випадково
4. **Симуляція замовлення** — додає послугу і перевіряє, що ціна порахувалась
   правильно, а повторне додавання збільшує кількість, а не дублює рядок

### top-secret-test.js — панель адміністратора

Пін-код (правильний пускає, невірний ні), відкриття/закриття панелі,
кількість пунктів меню, замикання.

## Коли запускати

Після кожної суттєвої правки — особливо після зміни категорій,
масиву `PRICE_LIST` або видалення/перейменування функцій.

## Як додати свій тест

1. Поклади файл у `tests/`
2. Файл має завершуватись `process.exit(0)` при успіху, `process.exit(1)` при провалі
3. Додай назву у масив `SUITES` вгорі `run-all.js`

## Примітки

- Тести працюють **без мережі**: Supabase, шрифти й аналітика вимикаються заглушками
- Головний HTML шукається за списком `HTML_CANDIDATES` вгорі `smoke-test.js`.
  Якщо файл перейменують — додай нову назву туди
- `node_modules/` не комітиться (див. `.gitignore`)
