# Довідкові прайси

Текстові (`prays-*.txt`) і CSV (`gt-prices-full.csv`) версії прайс-листа —
для ручної звірки й копіювання. У коді **не використовуються**: справжнє
джерело правди для цін у застосунку — масив `PRICE_LIST` у `app.js`.

Якщо міняєш ціни в `app.js`, онови ці файли вручну для узгодженості
(або видали їх, якщо вони більше не потрібні для довідки).
